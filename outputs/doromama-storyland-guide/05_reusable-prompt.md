# 再利用用プロンプト

新しい台本を下に貼ります。日刊泥ママストーリーランドの参考動画と同じ編集で、次の7点だけを出してください。アレンジしないでください。参考にない演出を足さないでください。

台本が甘恋・日常日記・名前交換なら、編集指示を出す前に止めてください。テーマの直し方は `08_themes-and-plots.md`。店は異常な会計の入口であり、デートの舞台ではありません。

前提（守ること）:

- 画面は 1080×1920、9:16。黒帯は上に高さ19.4%（約372px）。その下にイラスト。
- 黒帯の右に丸アイコン（目隠しの女の子）。全尺固定。
- 上部文と中央字幕は別。上部文は全尺固定。中央だけ切替。フェードなし。
- 中央字幕は太ゴシック、白＋黒縁が基本。黄は台詞、青は安堵オチ、緑は決め台詞オチだけ。
- 画像を動かしても文字は動かない。
- 冒頭5秒で絵を2回以上切る。物の列挙は約0.3秒。
- いらすとやは静止画。手足の中割り・歩きサイクル・口パクは出さない。動きはカメラ、別ポーズ切替、人物差し替え、後ろ姿、歩くポーズの1枚、効果の6つだけ。`10_motion-and-voice.md`。
- ポーズは中央字幕の動詞と一致させる。腕立て伏せを、直す・支える・橋を押さえる、に使い回さない。走っている人のPNGを800px以上スライドさせない。腕や足の部位を回転させない。`12_sample-bridge-fix.md`。
- 動きは参考1本の型だけ。はい？なら冒頭ズームアウトと横パン。店の会話型ならクリップ内ズームはほぼ無しで、アングル・寄り・重なりで動かす。全カットにKen Burnsを付けない。
- YouTubeのボタン、自動字幕、曲名チップは入れない。
- ナレとBGMは0秒から最後まで。頭に無音を置かない。曲名表示を正式曲名にしない。キラの光だけでSEありとしない。声の製品名を原作として書かない。
- 声は速く平坦。幼い甘いキャラ声にしない。店員は短く機械的。48kHzステレオ。見本の春日部つむぎ／白上虎太郎を原作の声にしない。
- 事実・推定・未確認を分ける。

冒頭5秒の短い切替は省略しない。

## 2. 必要画像一覧

番号、内容、背景/人物/小物、検索語（断定しない）。制作素材に参考画面を使わない。

## 3. 各画像の構図・加工指示

画角、向き、見切れ、色変更、反転、拡大、合成の有無。金銀は紙証書の色変更を優先。

## 4. 字幕の文言・改行・表示タイミング

上部文（1行または3行、全尺固定）と、中央字幕の一覧。句読点と改行を正確に。色。最大2行を基本。

## 5. 画像の動きとキーフレーム

開始終了スケール、移動方向、距離、拡縮の中心、直線かどうか、画像全体か人物だけか。字幕は動かさない。数値は1080×1920と％で書く。

## 6. 音声の配置

BGM / ナレ / SE を分ける。ナレとBGMは全尺。ナレを前に出す。YouTubeから抜かない。キラSEは未確認と書く。

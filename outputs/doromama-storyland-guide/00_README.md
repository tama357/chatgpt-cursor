# 日刊泥ママストーリーランド 制作ガイド

調査日: 2026-09-11  
目的: チャンネルの編集方法を、別の編集者が再現できる形で残す。独自アレンジはしない。  
今回やらないこと: 新しい動画の制作、発注者への送信、SNS公開。

## 先に結論

このチャンネルの型は次のとおりです。

1. 縦動画（9:16）。尺は約55〜69秒。
2. いらすとや風のイラストを、黒帯の下いっぱいに置く。
3. 上部に黒い帯、右に目隠し付きの丸アイコン、帯の中に白い固定文。
4. 黒帯のすぐ下に、白い太字・黒い縁の中央字幕。話者やオチでは黄・青・緑もある。
5. 冒頭5秒で画像を何度も切る。ズームアウト、横パン、3分割、集中線を場面に応じて使う。
6. エンドカードや登録誘導は、動画本体には入っていない。

音声は、再生音を残さず聞いて記録した。詳細は `06_audio-listen-notes.md`。正式曲名・声の製品名・キラSEは未確認のまま。

## 事実 / 推定 / 未確認

各レポートは項目ごとに分けています。

- **確認済み**: 映像で見えたこと。時刻と動画を書く
- **推定**: 見た目から判断したこと。根拠を書く
- **未確認**: 正式曲名、声の製品名、キラSE、公式台本、素材の入手元、書き出し設定の一部

## 調査の制約

- cursor-ide-browser はタブを開けなかった。Chromeで `video` 要素を保存して測った。
- YouTubeの音源ファイルは残していない。再生音を聞いて記録しただけである。
- 既存資料の数値（黒帯9.4%など）は正解にせず、原作で測り直した。
- 参考画面は構図の記録だけに使う。納品素材にしない。

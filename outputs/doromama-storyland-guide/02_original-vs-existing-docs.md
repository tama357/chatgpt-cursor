# 原作・既存資料・再現動画の違い

## 結論

既存資料は「はい？」の冒頭5秒を中心に書かれています。レイヤーの分け方（黒帯 / アイコン / 上部文 / 中央字幕を別にする）は原作と一致します。一方、数値・上部文の更新・字幕の行数・BGMの使い回しは、原作5本と食い違います。仮想画像のフォルダは、今回のディスク上にはPNGがありませんでした。

再現動画（生成画像の5秒）は、このフォルダにも `doromama-edit-template` にも見つかりませんでした。未確認です。

## 資料の種類

| 種類 | 場所 | 今回の扱い |
|---|---|---|
| 原作 | YouTubeの5本 | 正解。映像で確認したことだけを採用 |
| 既存の完コピ指示 | `Documents/doromama-edit-template/capcut/はい_冒頭5秒_完コピ指示書.md` | 分析対象。数値は再測定 |
| Descript指示とJSON | 同フォルダ `descript/はい_冒頭5秒/` | 仮画像前提。黒帯9.4%は使わない |
| 制作マニュアル・CapCutテンプレ | `制作マニュアル.md` `capcut/テンプレ設定.md` | 運用用の決め。原作ルールと混同しない |
| assets | `descript/.../assets` と `assets_shared/overlay` | テキストだけ。PNGはGit対象外で未検出 |
| 保存済み画面 | 依頼文で指定 | テンプレ内に画像ファイルなし。今回新たに撮影 |

## 一致したこと（確認済み）

- チャンネル名、基準URL、タイトル「はい？」
- 上部3行と中央字幕は別レイヤー。01の1.60秒で中央が「金」でも上部3行は残る
- 中央字幕は白＋太い黒縁、太ゴシック。フェードは見えない
- 画像を動かしても、黒帯・アイコン・字幕の大きさは変わらない
- 金・銀の証書にキラ（映像の光）。普通の紙証書にはキラがない
- 横パンは1枚の流れ。01の3.60〜4.20秒で金→銀→普通→ボタン
- 表彰台の数字は左から 2・1・3
- いらすとや風。人物は切り抜き合成に見える

## 食い違ったこと

### 1. 黒帯の高さ

| ソース | 値 | 区分 |
|---|---|---|
| 今回の原作（01の0.00秒、video要素） | 画面高さの **19.4%**。1080×1920換算 **372px** | 確認済み |
| CapCutテンプレ設定.md | 360px（約19%） | 今回の実測に近い |
| 完コピ指示・Descript JSON | 9.4% / 180px | 原作と一致しない |

9.4%は「YouTubeボタンを含めないための補正」と資料に書かれています。今回は video 要素だけを測り、右のいいね列を除いても約19.4%でした。制作では **約19%** を使い、9.4%には戻さないでください。

### 2. 上部文は途中で追記しない

制作マニュアルは「10〜15秒ごとに追記」と書いています。  
原作5本では、焼き込みの上部文は最初から最後まで同じでした。

途中で増えて見える文字は、YouTube自動字幕です。01では「卒業少々」など誤変換が黒帯に重なります。焼き込みではありません。

### 3. 上部文はいつも3行ではない

| 動画 | 焼き込み上部文 | 確認時刻 |
|---|---|---|
| 01 はい？ | 3行の話の導入 | 0.00〜68.00 |
| 02 晴れが好き | 3行の能力説明 | 0.00と67.00 |
| 03 髪の長さがランダム | **1行のタイトル** | 0.00と57.00 |
| 04 秘密が通貨の世界 | **1行のタイトル** | 0.00と58.00 |
| 05 三人で暮らそうね | 3行の話の導入 | 0.00と54.00 |

「毎回3行のスレ」はチャンネル全体の決まりではありません。

### 4. 中央字幕は3行もある。色も白だけではない

テンプレは「3行禁止」「通常は白、例外で青」です。原作では次がありました。

- 3行: 03の3.00秒「今日は髪に埋もれて / モンジャラみたいに / なってるし」
- 黄: 04の2.00秒「5シークレットになります」、01の45.50秒付近の台詞
- 青: 02の67.00秒「無事でよかった！」
- 緑: 05の54.00秒「母さんと三人で暮らそう」

白が基本、という点は合っています。禁止ルールとしては原作と違います。

### 5. BGMは1曲の使い回し、と断定できない

テンプレは「チャンネル指定の同じ音源」と書いています。  
画面左下のYouTube音楽表示は、動画で違います。

| 動画 | 画面に見えた表示名 | 区分 |
|---|---|---|
| 01 | 〇〇果汁１００％ | 確認済み（YouTubeの表示。正式曲名ではない） |
| 02 | タイ、ハマチ | 同上 |
| 04 | 魔本 | 同上 |
| 03・05 | この画面では曲名なし | 未確認 |

音は聞いて記録した。5本とも低い音が全尺ある。同じ1曲のファイルかどうかは未確認。表示名を正式曲名にしないでください。詳細は `06_audio-listen-notes.md`。

### 6. 冒頭5秒の切替時刻

完コピ指示のカット順は、01の原作とおおむね一致します。ずれは ±0.10〜0.20秒です。YouTubeはフレーム単位で止まりません。

白フラッシュは、01の1.40秒で確認しました。黒帯と字幕が残ったまま画像エリアだけ白です。読み込みノイズではなく、映像に入っています。確認済みです。長さは0.20秒サンプリングのため 0.10〜0.20秒程度。推定です。

### 7. 仮画像

Descriptの `A_gym_three_seats.png` などは、指示書どおり差し替え前提です。今回フォルダ内にPNGはありませんでした。`make_assets.ps1` が色付きの仮画像を作る脚本です。原作の複製ではありません。

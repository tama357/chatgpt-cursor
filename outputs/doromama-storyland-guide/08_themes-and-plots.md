# テーマと展開（ChatGPT貼り用）

調査日: 2026-09-11  
対象: 日刊泥ママストーリーランド  
目的: 画面の型だけ真似して、ほのぼの恋愛や日常日記になるのを止める。

原作の台本・能力・オチは複製しない。**型だけ**使う。

## 先に貼る文

台本を書く前に、下の枠をChatGPTへ貼る。編集指示（`05_reusable-prompt.md` / `07_chatgpt-latest-3.md`）は、テーマが決まってから貼る。

```
あなたは日刊泥ママストーリーランド用の、新しいオリジナル台本を考えます。
参考動画の文章・能力・オチはコピーしないでください。話の型だけ使います。

このチャンネルの話は、2ちゃんねる風の創作スレです。
ほのぼの恋愛、店員との淡い恋、名前交換、自己啓発、商品紹介、ただの日常日記ではありません。

【毎回同じ4段】
1. 0〜3秒で異常ルールが分かる（能力／別世界の決まり／呪われた物／成績で運命が決まる、など）
2. 日常での軽い実例を2〜4個（便利、恥ずかしい、ちょっと得する）
3. 欲が出る、制限が来る、災害や人間関係でルールが裏目に出る
4. 最後の1〜2文でタイトルや道徳をねじる。皮肉、見捨て、請求、公開、安堵の直後の別意味。甘い勘違いで終わらない

【尺】55〜69秒で語れる量。49秒以下は短い。80秒超は切る。

【一人称】女の子が多い。地の文は「私」。店員・男・機械の返事だけ別声にする前提で書く。

【やってはいけない話】
- コンビニ・カフェで店員と仲良くなる、レシートに好意、裏に名前を書く、照れ笑い
- 「好きだったのに、私はプリンの人だった」のような甘いオチ
- 感動の再会、感謝で終わる、努力が報われる、友達が増える
- 原作と同じ能力（手を叩いて位置入れ替え、床に触れて母・カエル・騎士、髪の長さが毎日変わる、秘密が通貨、卒業証書が金銀普通と暗黒ボタン、浮気相手の名前で呼ぶ）
- 原作の固有名詞（サチコ、トモカズ、シークレットという単位そのもの）

【オチの型（どれか1つ）】
A. 能力の悪用がバレて請求・警察・公開される
B. 助けた相手に置いていかれる／二人だけ帰る
C. タイトルの言葉が、最後だけ別の意味になる
D. 安堵した直後に、もっと大きい異常が残る
E. 自分だけルールの外側にいたと分かる

【今やること】
まずテーマ案を20個出す。各案は次の4行だけ。台本本文はまだ書かない。

1. タイトル（上部文用。1行、または能力紹介の2〜3行の核になる短い文）
2. 異常ルール（1文）
3. 悪化（1文）
4. 皮肉なオチ（1文）＋ 向ける参考型（はい？／ス イッチ／晴れが好き／秘密が通貨／髪ランダム／三人で暮らそうね のどれか1つ）

20個のあと、いちばんチャンネルに近い案を3つだけ推してください。
恋愛に寄せた案は推さないでください。
```

テーマを選んだら、次を貼って台本を書かせる。

```
選んだテーマで、55〜69秒の一人称台本を1本書いてください。
中央字幕に切れる長さ（1文を1〜2行）で書いてください。
句読点は残してよいです。小説の地の文を長くしないでください。

構成秒の目安:
- 0〜8秒: 異常ルールと発覚
- 8〜25秒: 日常の実例（場所を2つ以上変える）
- 25〜48秒: 悪化。場所をさらに変える（夜、災害、店の外、家、署、など）
- 最後8〜15秒: オチ。最後の絵はレシートや小物のアップだけで終わらない

禁止:
- 店員との恋愛、名前交換、照れ笑いオチ
- 同じ店内だけ、同じ棚の前だけで完結
- 「ありがとうございます」「好きです」で終わる

参考にする編集の型は、あとで1本だけ指定します。今は文章だけください。
出力は台本本文のみ。解説は末尾に4行まで。
```

## 原作で確認した話の骨格

文章は複製しない。**段の動き**だけ見る。

| 動画 | 異常ルール | 日常例 | 悪化 | オチ | 感情 |
|---|---|---|---|---|---|
| はい？ | 卒業証書が金・銀・普通・暗黒ボタン。成績で決まる | 特典（旅行、温泉）の列挙 | 最下位で暗黒ボタン。黒いバス、行方不明の噂 | ボタンで帰れる。タイトル「はい？」と呼応 | 競争→不安→逃げ |
| ス イッチ | 手を叩くと位置入れ替え。大きい物は無理など制限あり | 階段、電車、リレー | 火事、友人と入れ替わり、瓦礫、落下 | 歯と入れ替わる。ドローン代を請求される | 便利→危機→皮肉な請求 |
| 晴れが好き | 床に触れると母・カエル・騎士がランダム | 学校への送迎、電車で騎士、15分制限 | 浸水、カエルしか出ない | 龍が出て雨が止む。青字幕の安堵 | 能力→災害→安堵（例外的に救い。甘恋ではない） |
| 秘密が通貨の世界 | 秘密がお金。単位はシークレット | 麻辣湯の会計、耳打ち、お釣り | バッグや別荘を秘密で買う。裏取引 | 署に届く。「そんなぁ…」夜道で泣く | 便利→欲→公開・処罰 |
| 髪の長さがランダム | 毎日髪の長さが変わる | 坊主、髪に埋もれる、出産時のパニック | 撮影当日まで続く | 「またかよ！」予定が壊れる | 不便の連続。甘い着地ではない |
| 三人で暮らそうね | 彼氏を浮気相手の名前で呼んでしまう | バーで二人と鉢合わせ | 取り繕い、関係が壊れる | 「母さんと三人で暮らそう」は男2人の話。女は置いていかれる（緑字幕） | タイトルのねじれ。見捨て |

「秘密が通貨」を参考型にしても、話は恋愛にしない。店は**異常な会計の入口**である。店員は機械的な窓口である。

## 4段の書き方

1本あたり、先にこの4行を埋めてから本文を書く。

1. **フック**（0秒で口に出せる1文）  
   悪い例: 「コンビニで買い物をすると」  
   よい例: 「私は手を叩くと位置を入れ替えられる」「麻辣湯食べに行くと、5シークレットになります」
2. **実例**（絵が変わる場所を書く）  
   家、校舎、駅、店、車内、夜道、のうち2つ以上。同じ棚の前だけは不可。
3. **悪化**（ルールを得に使った結果）  
   買う、助ける、隠す、成績を上げる、のどれかが裏目。
4. **ねじれ**（タイトルの言葉を最後だけ別意味にする）  
   請求、公開、置き去り、撮影失敗、ボタンで帰宅。名前交換の照れではない。

## 新作テーマ例

原作の複製ではない。ChatGPTが「似た話が足りない」と言ったときの種。  
使うときは1つだけ選ぶ。能力とオチを混ぜない。

各項目の「向ける型」は編集の型である。話をその動画のコピーにしない。

### A. 能力（制限つき）

向ける型の目安: ス イッチ、晴れが好き

1. **瞬きするたびに5秒戻る**  
   制限: 連続10回で鼻血。日常: テストの書き直し、電車の扉。悪化: 事故を止めようとして瞬きしすぎ、周囲だけ時間が進む。オチ: 止めた相手から「何回も同じこと聞くな」と請求される。

2. **鏡の自分と1日交代**  
   日常: 授業を鏡側に押し付ける。悪化: 本番の面接が鏡側の日。オチ: 採用通知が鏡の住所に届く。自分の部屋には不採用。

3. **嘘をつくと相手の声になる**  
   日常: 欠席連絡がうまくいく。悪化: 大事な告白も相手の声。オチ: 録音が残り、相手の声で自分を嫌っている。

4. **影を踏むと相手の予定が見える**  
   日常: テスト範囲、バイトシフト。悪化: 自分の影が消える日が来る。オチ: 予定表に「あなたは今日いない」。

5. **握手すると相手の昨日が見える**  
   日常: 友人の失敗を先に知る。悪化: 面接官と握手。オチ: 見えた昨日は「この子を落とす打ち合わせ」。

6. **「大丈夫」と言うたびに指が1本透明になる**  
   日常: 職場で使いすぎる。悪化: 災害で何度も大丈夫。オチ: 救助の写真に自分が写っていない。

7. **ドアを3回ノックすると昨日の自分が出る**  
   日常: 宿題を昨日にやらせる。悪化: 昨日の自分が部屋を占領。オチ: 今日の自分がドアの外に出される。

8. **傘を差すと自分の上だけ雨が止む。代わりに誰かの家が浸水する**  
   日常: 通学が楽。悪化: 大雨の日に差す。オチ: 浸水した家が自分の家。母が濡れながら待つ。

### B. 世界の決まり（店にしてもよい。恋はしない）

向ける型の目安: 秘密が通貨の世界

9. **欠伸が通貨**  
   会計: 「3あくびになります」。正直者で退屈しない人は貧乏。悪化: 別荘を大きな欠伸で買う。オチ: 病院の患者から盗んだ欠伸だと署に届く。

10. **値札が「今いちばん隠したいこと」**  
   店で弁当を取ると値札に秘密が出る。悪化: 高いバッグの値札で他人を脅す。オチ: 自分の値が電子掲示板に出ている。

11. **レジを通すと「最後に捨てたもの」を言わされる**  
   日常: 恥ずかしいが安い。悪化: 捨てた日記を言わされ、後ろの客が録音。オチ: その音声が「通貨」として売られている。

12. **ポイントカードが他人の秘密を貯める**  
   日常: 貯まると割引。悪化: 満タンで別荘内見。オチ: カード会社から「あなたの分は売却済み」と通知。

13. **レシートに本音が出る世界（恋愛にしない版）**  
   ルールは会計だけ。日常: 先生のレシート、家族の夕食。悪化: 他人の本音を売って稼ぐ。オチ: 自分の本音レシートがフリマに出ている／母がそれを見ている。店員は窓口。好きにはならない。名前は書かない。

14. **既読が寿命**  
   LINEの既読1つで1時間減る。日常: 既読しない生活。悪化: 仕事の既読を強制される。オチ: 最後の既読が自分の遺書。

### C. 学校・成績・儀式

向ける型の目安: はい？

15. **席替えで将来の死因が机に書かれる**  
   日常: 窓際は「老衰」で人気。悪化: 自分の机が「今日」。オチ: 書かれていたのは席替え係の字で、係が行方不明。

16. **泣いた回数で内申が決まる**  
   日常: 教室で泣く競争。悪化: 本番で泣けない。オチ: 首席の子の涙が作り物だと放送される。自分は泣きすぎて単位を落とす、でも家には帰れる。

17. **給食当番の順番で、その日の記憶の持ち主が決まる**  
   日常: 美味い日は取り合い。悪化: 卒業アルバムの日当番。オチ: アルバムに自分の顔がない。当番が持って帰った。

18. **テストの答案が「昨日見た夢」で採点される**  
   日常: いい夢を見る薬が出回る。悪化: 薬の副作用で他人の夢。オチ: 答案に担任の秘密が書いてあり、署へ。

19. **名前を呼ばれると、呼ばれた場所の記憶が消える**  
   日常: 掃除当番を忘れられる。悪化: 避難訓練で名前を連呼。オチ: 家の場所を忘れ、校門の前で止まる。

### D. 見た目・毎日抽選

向ける型の目安: 髪の長さがランダム

20. **顔が昨日の検索履歴になる**  
   日常: 変な検索の翌日が地獄。悪化: 証明写真の前日。オチ: 撮影会場の掲示が自分の検索全文。

21. **声が、最後に聞いた曲のサビになる**  
   日常: 授業中に口が歌う。悪化: 面接。オチ: 内定電話もサビで、相手が切る。

22. **服が「昨日一番近づいた人」の制服になる**  
   日常: 先生に近づくと翌日が職員室。悪化: 病院の前日。オチ: 撮影当日、知らない誰かの喪服。

### E. 家族・同居のねじれ

向ける型の目安: 三人で暮らそうね

23. **母親の中身が毎日抽選。顔は同じ**  
   日常: 弁当の味で当たる。悪化: 進路の話をした日が別人。オチ: 「三人で話し合おう」は、母役の抽選3人が自分を置いて決める。

24. **ペットが飼い主の嘘だけ喋る**  
   日常: 家庭訪問が怖い。悪化: 結婚式の挨拶。オチ: ペットが新郎側につき、自分だけ残る。

25. **鏡の中だけ、亡くなった親がいる**  
   日常: 相談できる。悪化: 鏡を割る事故。オチ: 割れた破片の向こうで、親が「こっちに来い」と言う。行かない。請求でも恋愛でもない。残される。

### F. 災害で能力が裏目

向ける型の目安: 晴れが好き、ス イッチ

26. **拍手すると近くの火が消える。代わりに別の家が燃える**  
   日常: コンロの消し忘れ。悪化: 街の火事で拍手。オチ: 消えたのは隣。燃えたのは自分の家。消防から消火協力金。

27. **電車の吊革を握ると、一番行きたくない場所に着く**  
   日常: 学校を避けられる日もある。悪化: 避難で吊革。オチ: 着いたのが浸水した自宅。母が待つ。

28. **通知1件で、誰かの秘密が1行増えるメモ帳**  
   日常: 通知オフ生活。悪化: 災害速報が連続。オチ: メモ帳の最終行が自分の居場所。見知らぬ番号から「署まで届いてます」。

## 1テーマの展開を埋める型

ChatGPTに「展開が薄い」と言われたとき、この穴埋めだけさせる。

```
タイトル:
異常ルール（制限を1つ）:
発覚した場面（0〜3秒の絵）:
日常例1（場所A）:
日常例2（場所B）:
日常例3（短い。列挙するなら0.3〜1秒向け）:
欲を出した行動:
裏目の出来事（場所C。店の外か夜か災害）:
最後の絵（小物アップ禁止。人か場所）:
オチの1文（タイトルの言葉をねじる）:
使わない要素（恋愛、名前、感謝で終える、を明記）:
参考編集型（1つだけ）:
```

## レシート見本が外れた理由（短く）

`honne_receipt_sample.mp4`（本音が出るレシート）は、画面の黒帯・字幕位置は近い。話がチャンネルと違う。

外れた点:

- フックが「コンビニで買い物」で、異常ルールが後回し
- 店員の好意、通い詰め、名前、照れ笑い（甘恋）
- オチが「プリンの人としか覚えてなかった」（甘い勘違い）
- 場所が店内の同じ棚ばかり。秘密が通貨は店のあとバッグ・別荘・夜道・署へ出る
- 49.6秒で短い

同じ「レシートに文字が出る」でも、上の13番（本音を売る→自分のが売られる）なら型は合う。甘恋版は捨てる。

詳しい直し方は `09_sample-receipt-fix.md`。

# チャンネル共通の制作ガイド

対象: 日刊泥ママストーリーランドのYouTube Shorts  
根拠: 2026-09-11に確認した原作5本。独自の演出は足さない。

読み方: 「確認済み」は映像で見えたこと。「推定」は見た目からの判断。「未確認」は音声や公式情報の不足。

---

## 1. チャンネルの特徴

縦のイラスト物語です。2ちゃんねる風の創作スレを、いらすとや風の絵と短い字幕で進めます。チャンネル説明（外部サイト転記）ではオリジナル創作とされています。確認済みなのは映像の型だけです。

話の型の具体例は `08_themes-and-plots.md`。ほのぼの恋愛や店員との淡い恋にはしない。

毎回同じもの:

- 9:16
- 上部黒帯、右の丸アイコン（目の位置を黒い帯で隠したピンクの服の女の子）
- 黒帯の下をイラストで埋める
- 中央の太い字幕。フェードなし
- エンドカードなし

台本に応じて変えるもの:

- 上部文の行数（1行タイトルか、3行の導入か）
- カットの速さ
- ズーム、横パン、3分割、雨、集中線
- 字幕の色（白が基本。黄・青・緑あり）
- オチの一言

## 3. 素材の選び方と構図

いらすとや風の線と塗りです。写真や実写は使われていません。確認済みです。  
同一ファイルのURLは、画面だけでは断定できません。近いものを探す検索語にします。

よく使う構図:

- 全身または膝上（駅、バー、教室）
- バストアップ・顔アップ（会話、オチ）
- 小物アップ（証書、ボタン、チケット、スマホ）
- 広角の場所＋手前の人物（01の卒業式、02の駅）

加工（原作で見えたこと）:

- 同じ人物の服装・髪型だけ変える（03）
- 紙の証書を金・銀に塗る（01）
- 3分割（02の0.00台後半〜3.00秒）
- 人物を背景から切り抜いて重ねる

見切れ: 意図的に左右を切る（01の銀の左に金、ボタンの左に紙証書）。確認済みです。

## 4. カット割り

基本はハードカットです。クロスフェードは見えていません。確認済みです。

冒頭5秒:

- 5本とも、5秒以内に画像が2回以上変わります。確認済みです。
- 01は特に速い。金・銀・普通はそれぞれ約0.3秒。確認済みです。
- 02・04・05は同じ場所の別アングル切替が多いです。

動きの使い分け（確認済みの例）:

| 動き | 使うとき | 例 |
|---|---|---|
| ズームアウト | 顔アップから人数・場所を見せる | 01 0.00〜0.60 体育館 |
| 弱いズームイン | 人物を強調 | 05 2.00〜3.00 トモカズ＋集中線 |
| 横パン | 横に並ぶ物を順に見せる | 01 3.60〜4.20 |
| 3分割 | 「ランダムに3つ」など並列 | 02 3.00 |
| 静止の切替 | 会話の切り返し | 04 店員と客 |
| 白フラッシュ | 短い強調（任意に近い） | 01 1.40 約0.2秒 |

イージングは、01のズームアウトと横パンが一定速度に見えます。推定です。バウンドや画面揺れは見えていません。確認済み（非使用）。

字幕は画像と一緒に拡大しません。確認済みです。

## 5. 文字

### 上部文の2型

A. 3行の導入（01、02、05）  
例（01、確認済み）:

```
うちの学校の卒業証書は
金・銀・普通・
暗黒ボタン、があって…
```

B. 1行のタイトル（03、04）  
例: `髪の長さがランダム` / `秘密が通貨の世界`

どちらも全尺固定でした。確認済みです。

### 中央字幕

- 1行または2行が基本。3行もある（03）。
- 切替は瞬間。フェードなし。
- 同時に2つの中央字幕は出さない（01の「金」のとき2行導入は消える）。
- 画像が動いても字幕は固定。

色:

| 色 | 使い方 | 根拠 |
|---|---|---|
| 白＋黒縁 | 地の文・ナレ相当 | 5本の大部分。確認済み |
| 黄＋黒縁 | その場の台詞 | 04 2.00、01 45.50。確認済み |
| 青＋黒縁 | 安堵のオチ | 02 67.00。確認済み |
| 緑＋黒縁 | オチの決め台詞 | 05 54.00。確認済み |

黄色を「強調したいから」と全編に使わないでください。原作は話者やオチのときだけです。

## 6. 音声

再生音を残さず聞いた。詳細は `06_audio-listen-notes.md`。

BGM:

- 5本とも、低い音が0秒から最後まで続く。推定（周波数の図）
- YouTubeの表示名は動画で違う。01「〇〇果汁１００％」、02「タイ、ハマチ」、04「魔本」。03・05はチップなし
- 表示名は正式曲名ではない。同じ1曲とも言えない
- 動画に曲名を焼き込まない
- YouTubeから抜かない。発注者の音源を0秒から最後まで置く
- ナレより小さく、下に敷く。推定

ナレーション:

- 0.1秒以内に始まる。頭の無音なし。確認済み
- 一人称。中央字幕とほぼ同時。速い。長い息継ぎがない。確認済み
- 機械音声に近い。推定。製品名は書かない
- 地の文と、店員・男などの台詞は声を分ける。推定（05・04・01）
- 原稿の正本は焼き込み字幕。聞き取りの誤変換（髪→神、床→みか）は使わない

SE:

- 金銀のキラ音は、聞いても特定できなかった。光だけでは入れない。未確認
- 04の「ピッ」（約5秒、黄字幕）は電子音の可能性。推定。入れるかは発注者確認
- 02の雨SEは未確認
- 01の終わり「はい！」は言葉。効果音だけではない。確認済み

## 7. 台本から編集指示を作る手順

1. 台本を読む。フック（能力・異常な前提）とオチを1行ずつ決める。
2. 上部文を決める。短いタイトルなら1行。スレ風の導入なら3行。全文を途中追記しない（今回の5本に合わせる）。
3. 中央字幕を1〜2行に分ける。3行は長い説明のときだけ。
4. 字幕1つに絵を1枚が基本。同じ場所の会話はアングルを変える。
5. 冒頭5秒で絵を2回以上切る。01のように物を列挙するなら0.3秒の連続切替を使う。
6. 動きは意味があるときだけ。ズームインを全カットに付けない。
7. 黄・青・緑は台詞とオチだけ。
8. 効果（雨・集中線・キラ）は、そのカットの意味に合わせて最大数か所。
9. 黒帯・アイコン・字幕スタイルはロックする。
10. 書き出し前に、参考の同じ型の1本と並べて冒頭5秒を見る。

- 参考にない矢印

- 曲名の焼き込み
- 金銀以外へのキラ（01では普通とボタンにキラなし）

## 9. 5本の比較

根拠は各動画のレポートと代表画面です。1本だけの特徴を全体の決まりにしません。

### 5本で共通（確認済み）

- 9:16、黒帯、目隠しアイコン、いらすとや風
- 中央字幕は黒帯の下。太字。フェードなし
- 画像ズームに字幕が連動しない
- エンドカードなし
- 冒頭5秒以内に絵が2回以上切れる

### 多くにあるが例外もある

- 上部3行: 01・02・05。例外は03・04の1行タイトル
- 白字幕: 5本とも基本。例外で黄・青・緑
- 2行字幕: 多い。例外で1行ラベル（01の金）と3行（03）
- YouTube曲名チップ: 01・02・04で見えた。03・05は画面にチップなし。音としては5本とも低い帯がある

### 特定の動画・場面だけ

- 横パン: 01の3.60秒付近だけ確認
- 白フラッシュ: 01の1.40秒
- 3分割: 02の3.00秒
- 楕円ビネット: 02の5.00秒
- 雨: 02
- 緑オチ: 05の54.00秒
- 青オチ: 02の67.00秒
- 黄の店員台詞: 04
- 表彰台2-1-3: 01の4.40秒

### 台本に応じて変える

- 上部文の文言と行数
- カットの速さ（列挙は0.3秒、会話は1〜2秒）
- 場所・人物・効果
- オチの色と構図

### 毎回固定

- 黒帯の位置と高さの型
- アイコンの絵柄
- 中央字幕の置き場
- イラストを帯の下に埋める

### 再現度に影響が大きい

1. 黒帯と字幕を画像と別レイヤーにする（01の1.60秒「金」）
2. 冒頭の切替速度（01の金銀普通）
3. 上部文を途中で書き換えない
4. いらすとや風と切り抜き合成
5. YouTube UIを入れない

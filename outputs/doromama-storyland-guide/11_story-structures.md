# 10本の話の構成と展開

調査日: 2026-09-11  
対象: 日刊泥ママストーリーランドのストーリー型Shorts  
目的: 新しい台本を書く前に、話の段だけを真似る。文章・能力・オチは複製しない。

11秒の「お馬さん」再現動画は型が違うので入れていません。

精度:

- **確認済み**: 画面の焼き込み字幕と、以前の聞き取りで揃えたもの
- **サンプリング**: 2026-09-11に数か所の画面だけ見た（魔本／白い村／過去メガネ／両足をつけちゃいけない）。中盤は粗い
- **推定**: 聞き取りや自動字幕を直した箇所

---

## 毎回同じ4段

1. **フック**（0〜8秒）異常ルールが1文で分かる  
2. **日常**（8〜25秒）軽い実例。場所を2つ以上変える  
3. **悪化**（25〜48秒）欲・制限・災害・人間関係で裏目  
4. **ねじれ**（最後8〜15秒）タイトルや道徳を別の意味にする  

甘恋・名前交換・感謝で終わる、は10本のどれにもない。

| オチの型 | 該当 |
|---|---|
| 逃げ／ボタンで帰宅 | はい？ |
| 皮肉な請求 | ス イッチ |
| 安堵（例外。甘恋ではない） | 晴れが好き |
| 公開・処罰 | 秘密が通貨の世界 |
| 予定が壊れる | 髪の長さがランダム |
| タイトルのねじれ＋見捨て | 三人で暮らそうね |
| 変な召喚で着地 | 魔本 |
| 怖さが日常に落ちる | 白い村 |
| 「過去だから」と流す | 過去メガネ |
| 新しい縛りが始まる | 両足をつけちゃいけない |

## 新作を書くときの使い方

10本から**段の動きだけ**1つ選ぶ。能力と固有名詞は使わない。

ChatGPTに貼る文:

```
次の10本は、日刊泥ママストーリーランドの話の段だけです。文章はコピーしないでください。

共通は4段です。フック→日常→悪化→ねじれ。
甘恋、名前交換、感謝で終わる、は使いません。

今から新しいオリジナルを1本書きます。
上のどれか1本の「段の動き」だけ選んで、55〜69秒の一人称台本にしてください。
選んだ番号: （1〜10）
能力・固有名詞・オチの文言は変えてください。
```

選んだあとに `08_themes-and-plots.md` の禁止リストと、`10_motion-and-voice.md` の動きを足す。

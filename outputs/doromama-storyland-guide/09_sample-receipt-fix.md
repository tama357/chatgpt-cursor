# サンプル「本音が出るレシート」の直し方

対象ファイル:  
`outputs-doromama-sample-02-receipt/honne_receipt_sample.mp4`

制作指示書どおり、参考型は「秘密が通貨の世界」1本だけ。  
黒帯の高さ、丸アイコン、白と黄の字幕位置は、チャンネルの画面ルールに近い。

外れているのは**話**と、話に引きずられた**絵の単調さ**である。画面テンプレを直すより先に、テーマを捨てる。

この動画の再書き出しは、このメモでは行わない。

---

## 1. 何が違うか

原作「秘密が通貨の世界」の動き:

1. 店に入る  
2. 異常な会計（5シークレット、耳打ち、ピッ）  
3. 欲が出る（バッグ、別荘）  
4. 裏取引が署に届く  
5. 夜道で泣く  

サンプルの動き:

1. 店に入る  
2. レシートに店員の好意が出る  
3. 毎日通う  
4. 名前を書く  
5. 「プリンの人」としか覚えていなかった  

店を使ったことだけが同じ。あとは甘恋である。チャンネルの店は、異常ルールの窓口である。デートの舞台ではない。

フレームで見えたこと（ローカル再生。2026-09-11）:

- 背景がコンビニに見えず、ファイル棚のような列が続く
- レシートに英語の `Receipt?` と空の波線だけ。印字がない
- プリン、サラダ、パンの単体アップが多い。異常ルールが進まない
- 人物は笑顔と照れが中心。青ざめ、夜道、署がない
- 最後もレシートの寄り。場所が変わらない
- 尺 49.6秒。分析したストーリーはおよそ55〜69秒

---

## 2. 具体的にどうするか

順番を守る。編集ソフトの数値から入らない。

### 手順1. この台本を捨てる

「本音が出るレシート」の甘恋版は使わない。  
タイトルだけ残したい場合は、話を13番の型に差し替える（`08_themes-and-plots.md`）。

残してよい要素:

- 世界の決まりとして、紙に文字が出る
- 店員は短い黄字幕の窓口（「200円になります」ではなく、異常な単位の会計）

捨てる要素:

- プリン好きを見抜かれるほのぼの
- 毎日同じ時間に通う
- 夜勤でも会いに行く
- 裏に名前を書く
- 照れ笑い
- 「プリンの人としか覚えてなかった」

### 手順2. ChatGPTにテーマを20個出させる

`08_themes-and-plots.md` の「先に貼る文」を貼る。  
台本はまだ書かせない。

原田が見る基準:

- 0秒で異常が分かるか
- 恋・感謝・名前交換がないか
- 悪化が店の外に出るか
- オチが皮肉か、公開か、置き去りか、請求か

甘い案は採用しない。

### 手順3. 選んだ1テーマで台本を書かせる

`08` の2つ目の枠を貼る。  
出来たら次だけ確認する。

- 55〜69秒分あるか（目安 28〜36カット、場所は3つ以上）
- 最初の文が「買い物をしたら」だけで終わっていないか
- 最後の文が好意の勘違いではないか

### 手順4. 参考型を1本だけ決める

店の会計が入口なら「秘密が通貨の世界」。  
能力の制限と災害なら「ス イッチ」か「晴れが好き」。  
見た目の毎日変化なら「髪の長さがランダム」。  
成績や儀式なら「はい？」。  
呼称ミスと置き去りなら「三人で暮らそうね」。

3分割＋横パン＋黄店員＋紫渦を1本に混ぜない。

### 手順5. 編集指示を出させる

テーマ確定後に `05_reusable-prompt.md` か `07_chatgpt-latest-3.md` 末尾の型を貼る。

「秘密が通貨」型にするときの絵の最低条件:

| 区間 | やってよいこと | やってはいけないこと |
|---|---|---|
| 0〜5秒 | 店のアングルを2回以上切る。異常会計を黄字幕 | 普通の「200円になります」だけで世界観を出さない |
| 中盤 | 店を出て、バッグ・家・海・夜など別場所 | 同じ棚の前で表情だけ変える |
| 小物 | 端末、スマホ、札、紙は2〜3回まで | レシートアップを7回以上。英語の Receipt を出す |
| 顔 | 驚き、暗い顔、怒りマーク、泣き | 笑顔と舌出しだけで進める |
| 最後 | 夜道、署、家など新しい場所 | 白紙のレシート寄りで終わる |
| 尺 | 55〜69秒 | 50秒未満 |

背景は、コンビニなら商品棚・レジ・暖簾。オフィスのファイル棚を流用しない。

紙に文字を焼くなら日本語の短い一文だけ。中央字幕と二重にしない。空の波線と英語は使わない。

### 手順6. 細かい動き（秘密型）

見本は31カットとも区間内100%静止だった。秘密型では、ゆっくりズームを全カットに足さなくてよい。代わりに次を入れる。

- 0秒は全身、0.6秒は後ろ姿、1.0秒は店員、2.0秒は客の後頭部を手前に重ねる
- 「ピッ」や驚きは顔へ寄る。怒りマーク。顔を暗くする。集中線
- 店の外へ出る。最後は夜道など
- はい？の138%ズームと横パンは、この型に混ぜない

数値の書き方は `10_motion-and-voice.md`。

### 手順7. 声とBGM

見本の声は、機械音声という方向だけ合っている。チャンネルとは一致していない。

- 地の文が幼く甘い（見本は春日部つむぎ）。原作はスレを速く読む平坦な声
- 店員が丁寧な青年（見本は白上虎太郎）。原作は「5シークレットになります」のような短い窓口
- 見本は24kHz・モノラル。声が少しこもる。次は48kHzステレオ
- 速度1.17／1.12を原作の値にしない。字幕と同時なら、もう半歩速くて平坦でよい
- 0秒から声。頭の無音なし
- 画面にもコメントにも、声の製品名を原作として書かない
- BGMは低い音を下に敷く。目立つ短い旋律の仮BGMは寄せない
- YouTubeから抜かない

## 3. レシートをどうしても使うとき

甘恋版は使わない。下の4行だけ埋めてから本文を書く。

1. タイトル: 本音が出るレシート  
2. ルール: 会計の紙に、その場で一番売れる秘密が印字される。円では払えない  
3. 悪化: 他人のレシートを集めて高い物を買う。裏で取引される  
4. オチ: 自分のレシートが売られている／署に届く／母が見ている。「そんなぁ…」でよい。プリンの人は不可  

場所の最低セット:

- 店（会計）
- 家または学校（日常で得をする）
- 高い物の内見または夜の画面
- 最後は店の外

店員の黄字幕例（窓口。好意ではない）:

- 「3シークレットになります」
- 「ピッ」
- 「ありがとうございます」（機械的。恋の台詞にしない）

## 4. 今すぐChatGPTに出す順番

1. `08_themes-and-plots.md` の1つ目の枠（テーマ20個）  
2. 原田が1つ選ぶ  
3. `08` の2つ目の枠（台本）  
4. 参考型を1本指定して `07_chatgpt-latest-3.md` 末尾の型  
5. このファイルの手順5の表で絵を点検  

編集ソフトのカット表を先に作らせない。話が甘いと、画面を直しても同じ動画になる。

話の4段は近いのに絵と動きだけ外れた見本（そのままでいて）は、台本を捨てない。`12_sample-bridge-fix.md`。

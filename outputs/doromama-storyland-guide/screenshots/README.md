# 測定用画面について

このフォルダの画像は、**位置と構図を測るための記録**です。制作素材として使いません。原作のイラストを切り出して納品動画に貼らないでください。

## 何を撮ったか

- ChromeでYouTube Shortsを開き、`video`要素（再生中の映像）だけを保存した。
- ブラウザのタブ、アドレスバー、ページ全体は撮っていない。
- ただしYouTube側の操作UIが映像の上に重なって写る。測定対象から外す。

## 動画本体と、YouTubeの画面の区別

| 写っているもの | 扱い |
|---|---|
| 上部の黒い帯、丸アイコン、焼き込みの上部文、中央字幕、イラスト | 動画本体。再現する |
| 右のいいね・コメント・共有・リミックス | YouTubeの操作ボタン。入れない |
| 左下のチャンネル登録、動画タイトル | YouTubeの操作。入れない |
| 左下の曲名（例: 〇〇果汁１００％） | YouTubeの音楽表示。焼き込みではない。入れない |
| 黒帯に重なる薄い誤変換テキスト（例: 卒業少々） | YouTube自動字幕。焼き込みではない。入れない |
| 左上の再生ボタン・音量、右上の「…」 | YouTubeの操作。入れない |

## ファイル

- `key/` … ガイド用の代表画面（JPEG）。Gitに入れる
- `01_hai/` など … 0.2秒刻みの全フレーム（PNG）。ローカルに残る。Gitには入れない

全フレームは分析時に使った。容量が大きいのでリポジトリには代表画面だけを上げている。

## 測り方

- 原点は映像の左上
- 比率は、保存した映像フレームの幅・高さに対する％
- 1080×1920換算は、その％を掛けた値
- 再生解像度は動画によって 608×1080 と 1080×1920 があった。比率で記録する

## 2. 収益化に向けた基本方針

YouTube Studioに表示された広告収益化の参加要件は、登録者1,000人に加えて、次のいずれか。

- 過去365日間で有効な公開動画の総再生時間4,000時間
- 過去90日間で有効なショート動画の視聴回数1,000万回

直近48時間のペースは約2,700回／日であり、ショート1,000万回に必要な平均約11.1万回／日とは大きな差がある。このため、当面は次の組み合わせを採用する。

1. ショートで題材と切り口を検証する。
2. 成績の良いショートを4〜8分の通常動画に発展させる。
3. ショートから関連する通常動画へ誘導する。
4. 通常動画で有効な公開動画の再生時間を積み上げる。

## 3. 当面テストする2本柱

30日間は、次の2系列を同程度の本数で投稿し、感覚ではなく実績で主軸を決める。

### A. 話題の商品・イベントを短く解説

例：外食チェーン、新商品、イベント日程、企業発表、ゲーム関連ニュース。

強み：検索・話題性と相性がよく、公開直後に伸びる可能性がある。

注意：情報の寿命が短い。公開前に公式発表、日時、販売条件を確認する。

### B. 身近な科学・雑学

例：雨粒、雨雲、コップの水滴、動物の色など。

強み：季節に左右されにくく、通常動画やシリーズへ展開しやすい。

注意：既視感のある題材は、冒頭で意外な答えや誤解を示す。

### 主軸を決める判断基準

最低10本ずつ投稿し、次の順に比較する。

1. 登録者増加数／1,000再生
2. 視聴を継続した割合
3. 平均視聴率
4. 48時間後と7日後の視聴回数
5. 高評価・コメント・共有

再生数だけで決めない。登録と継続視聴につながる系列を主軸にする。

## 4. ショート動画の制作チェックリスト

### 企画

- [ ] 1動画1メッセージになっている
- [ ] 視聴者が知りたい答えを一文で説明できる
- [ ] 公式発表または信頼できる一次情報を確認した
- [ ] 「話題の商品・イベント」か「身近な科学・雑学」のどちらかに分類できる
- [ ] 成績が良ければ通常動画へ広げられる題材である

### 冒頭0〜1秒

- [ ] あいさつや前置きから始めていない
- [ ] 結論、驚き、疑問、誤解の訂正のいずれかを最初に置いた
- [ ] 最初の画面だけでテーマが分かる
- [ ] スマートフォンで読める短い文字にした

冒頭例：

- 「実は、雨粒は涙の形ではありません」
- 「一般入場できない日があります」
- 「発売日はネットと店頭で違います」

### 本編

- [ ] なくても意味が通る文を削った
- [ ] 2〜3秒ごとに映像、文字、構図のいずれかを変えた
- [ ] 重要な固有名詞、日付、条件を画面にも表示した
- [ ] 音声なしでも大意が伝わる
- [ ] 最後まで見る理由を途中に残した

### 終わり方

- [ ] 冒頭の疑問に答えている
- [ ] 不自然に引き延ばしていない
- [ ] 次の動画やチャンネルの継続価値を一言で示した
- [ ] 通常動画がある場合は関連動画として設定する

登録の呼びかけは、単なる「登録してください」ではなく、視聴者が得るものを伝える。

例：「身近な疑問を1分で解説します。次も見逃したくない方は登録を。」

## 5. 通常動画への展開ルール

次のいずれかを満たしたショートは、4〜8分の通常動画候補にする。

- チャンネル平均より登録者増加率が高い
- 視聴継続率または平均視聴率が明確に高い
- コメントで追加説明を求められた
- 同じテーマの複数動画が安定して伸びた

通常動画では、ショートの内容を単に引き延ばさず、背景、理由、比較、注意点、今後の見通しを追加する。

## 6. 当面の目標値

最初の改善目標として、次を置く。チャンネル実績が増えたら更新する。

- 視聴継続：22.5%から30%以上へ
- 登録者純増：1,000再生あたり2人以上
- 勝ち系列：30日間の比較で1つに絞る
- 通常動画：週1本を目安に、ショートの勝ち題材から制作する

目標値は合否判定ではなく、改善方向を確認するために使う。

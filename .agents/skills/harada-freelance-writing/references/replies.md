# 応募・返信文

相手が聞いている内容に答え、求められていない情報は足さない。日時・曜日・金額・納期・面談時間の長さを推測しない。日程提示が必要なら既存予定と候補日を確認し、原則20時以降・1日1件を守る。

CrowdWorksではメール型の長い挨拶や署名ではなく、チャットに貼れる自然な文面にする。依頼がある場合以外、Zoom・LINE・Chatwork・メールなど別の連絡方法を勝手に提案しない。

本人の経歴や経験は確認できた事実だけを使う。応募で必要な場合だけ、ポートフォリオ `https://harada-portfolio.vercel.app/` を添える。規約違反・アカウント貸与・過度な個人情報要求がある場合は、通常の応募文作成を進める前に懸念を示す。

送信の代行はこの資料の対象外。未確定の予定を確定扱いにしたり、下書き作成を送信完了と報告したりしない。

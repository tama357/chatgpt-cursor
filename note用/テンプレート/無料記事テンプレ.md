# 無料記事の構成テンプレ

用途：共感・発見・入口。有料への導線は最後に1段落まで。

想定文字数：1,200〜2,000字（noteにそのまま貼れる長さ）

---

## タイトル案（3つ出す）

1.
2.
3.

## 想定読者

- 誰：
- 今の困りごと：

## 素材の分け方

### あるある層（リサーチ・一般化）

- 同業・同時間帯の悩みとして書く文言：
- 参考にした論点（記事に出典URLは出さなくてよい。下書き末尾メモ用）：

### 本人事実層（事実メモのみ）

- （原田さんが確認済み／渡したメモのみ。空欄は使わない）

## 構成

### 1. 読者の状況に寄り添う導入（2〜4文）

あるあるで「自分のことだ」と感じる場面から入る。結論を急がない。

### 2. あるあるのつまずき → 必要なら本人の具体

一般的なパターンを先に示す。本人事実があるときだけ「私は〜」を足す。  
数字は事実メモにあるものだけ。

### 3. 気づき（1つに絞る）

抽象論ではなく、「何をやめる／何を決める」まで落とす。

### 4. 今日からできる小さな行動（1〜3個）

手順は短く。有料で出す詳細はここでは出さない。

### 5. 締め＋任意の導線（1段落まで）

有料がある場合は、何が詳しく書いてあるかだけ伝える。売り込み長文は禁止。

---

## 品質チェック

- [ ] です・ます調、一人称「私」は本人事実の箇所だけに限定できている
- [ ] あるあるを本人の成功談に見せていない
- [ ] 一文短め、文ごとに改行
- [ ] LLMっぽい総括（「まとめると」「重要なのは」）なし
- [ ] 体験の捏造なし
- [ ] 診断・効果保証・煽りなし

# note 運用フォルダ

定期投稿のためのカレンダーとルール。

| ファイル | 内容 |
|----------|------|
| `テーマ選定_YYYY-MM.md` | **ここだけ触る**。チェックボックスでテーマ選択 |
| `伸びるnote実行プレイブック.md` | スキ増やす優先順・タイトル（アフォーダンス）・冒頭 |
| `プロフィール設定メモ.md` | note自己紹介の貼り付け文 |
| `スキ振り返り.md` | タイトル変更の記録 |
| `通知カレンダー.md` | 選定タイミングとGoogleカレンダー通知 |
| `定期投稿ルール.md` | 頻度・役割・あるある／本人事実・承認後公開 |
| `テーマカレンダー_YYYY-MM.md` | テーマ詳細（あるある・本人事実のヒント） |
| `有料候補_YYYY-MM.md` | その月の有料候補の説明 |

原稿本体は `../下書き/`、公開後は `../公開済み/`。

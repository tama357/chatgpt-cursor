# note用（理学療法士×AI副業実践記）

原田さんの note マネタイズ用フォルダ。

## 方針

- メイン軸：理学療法士の本業あり × AI副業の実践記
- 無料記事：共感・失敗・小さな工夫（入口）／週3（月・水・金）
- 有料記事：手順・チェックリスト・失敗の詳細（実用）／月1・当面980円
- 下書きは AI、事実確認と「公開OK」は原田さん、承認後に AI が公開
- 文章は「あるある（リサーチ）」と「本人事実」を分ける

詳細：`運用/定期投稿ルール.md`

## フォルダ

| 場所 | 用途 |
|------|------|
| `運用/` | カレンダー、有料候補、定期投稿ルール |
| `テンプレート/` | 無料・有料の構成テンプレ、事実メモ |
| `下書き/無料/` | 無料記事の下書き |
| `下書き/有料/` | 有料記事の下書き |
| `画像/` | 表紙・本文画像 |
| `公開済み/` | 投稿後の控え |

## 執筆ルール

- `.cursor/rules/freelance-writing.mdc` に従う
- 体験していないことを体験したように書かない
- あるあるは一般化して書き、本人の「私は」は事実メモのみ
- 診断・治療の断定、効果保証、「必ず稼げる」系は書かない
- 本業は「疲れ・時間のなさ」程度の一般化まで。患者・同僚の特定は禁止
- 投稿・公開は原田さんの「公開OK」後のみ

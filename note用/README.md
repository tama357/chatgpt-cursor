# note用（理学療法士×AI副業実践記）

原田さんの note マネタイズ用フォルダ。

## 方針

- メイン軸：理学療法士の本業あり × AI副業の実践記
- 無料記事：共感・失敗・小さな工夫（入口）
- 有料記事：手順・チェックリスト・失敗の詳細（実用）
- 下書きは AI（Fable5）、事実確認と投稿は原田さん

## フォルダ

| 場所 | 用途 |
|------|------|
| `テンプレート/` | 無料・有料の構成テンプレ、事実メモ |
| `下書き/無料/` | 無料記事の下書き |
| `下書き/有料/` | 有料記事の下書き |
| `公開済み/` | 投稿後の控え（任意） |

## 執筆ルール

- `.cursor/rules/freelance-writing.mdc` に従う
- 体験していないことを体験したように書かない
- 診断・治療の断定、効果保証、「必ず稼げる」系は書かない
- 投稿・公開は原田さんの承認後のみ

## 価格の目安（最初）

有料は 500〜1,500円の実用パックから。

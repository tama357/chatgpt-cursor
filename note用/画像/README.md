# note用画像

生成：Cursor GenerateImage（16:9）。日本語文字は画像に入れず、雰囲気写真で統一。

## 使い分け

| ファイル | 用途 |
|---------|------|
| `note-cover-paid-checklist-v2.jpg` | 有料記事の見出し画像（表紙） |
| `note-body-paid-checklist-v2.jpg` | 有料記事の本文画像 |
| `note-cover-free-night-desk-v2.jpg` | 無料記事の見出し画像（表紙） |
| `note-body-free-after-work-v2.jpg` | 無料記事の本文画像 |

推奨サイズ：表紙 1280×670。

## noteへの入れ方（本文）

1. 編集画面で入れたい位置にカーソル
2. 左の「＋」→「画像」
3. 上の対応ファイルを選ぶ

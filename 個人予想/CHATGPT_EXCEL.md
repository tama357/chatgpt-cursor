# 個人競輪 Excel — ChatGPT 共有ガイド

原田さんが ChatGPT に Excel の内容を渡すとき、**この2ファイル**を使います。

## ファイルの場所（リポジトリ内）

| 用途 | パス |
|------|------|
| 予想記入 | `個人予想/excel/競輪_個人_予想記入シート.xlsx` |
| 集計 | `個人予想/excel/競輪_個人_予想集計シート.xlsx` |

### 絶対パス（この環境）

```
/workspace/個人予想/excel/競輪_個人_予想記入シート.xlsx
/workspace/個人予想/excel/競輪_個人_予想集計シート.xlsx
```

## Google Drive と同期している場合

Drive 上で同じ名前のファイルを管理している場合は、**Cursor が更新したリポジトリ内のファイル**が最新です。

ChatGPT に渡す手順（原田さん）:

1. Google Drive から上記2ファイルを開く（または PC に同期されたフォルダを開く）
2. ChatGPT のチャットに **ファイルを添付**する
3. 「今日の個人競輪の予想記入と集計を確認して」と指示する

## ChatGPT に伝えるとよい情報

- シート名は月別（例: `202609` = 2026年9月）
- 1日5行（予想番号1〜5）
- 予想記入は A〜K 列、結果は L〜N 列
- 集計シートの B〜O 列は数式（触らない）

## Cursor 側の自動更新

原田さんが Cursor で次のように伝えると、上記 Excel に自動で書き込まれます。

- **予想**: 「今日の競馬と個人競輪を予想して」
- **結果**: 「昨日の結果を確認して」

原田さんが JSON を作ったり、コマンドを打つ必要はありません。

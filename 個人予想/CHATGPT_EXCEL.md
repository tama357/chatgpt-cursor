# 個人予想 Excel — ChatGPT 共有ガイド

原田さんが ChatGPT に Excel の内容を渡すとき、**この4ファイル**を使います。

## ファイルの場所（リポジトリ内）

| 用途 | パス |
|------|------|
| 競馬 予想記入 | `個人予想/excel/競馬_予想記入シート_2026年9月.xlsx` |
| 競馬 集計 | `個人予想/excel/競馬_予想集計シート_2026年9月.xlsx` |
| 競艇 予想記入 | `個人予想/excel/競艇_予想記入シート_2026年9月.xlsx` |
| 競艇 集計 | `個人予想/excel/競艇_予想集計シート_2026年9月.xlsx` |

### 絶対パス（この環境）

```
/workspace/個人予想/excel/競馬_予想記入シート_2026年9月.xlsx
/workspace/個人予想/excel/競馬_予想集計シート_2026年9月.xlsx
/workspace/個人予想/excel/競艇_予想記入シート_2026年9月.xlsx
/workspace/個人予想/excel/競艇_予想集計シート_2026年9月.xlsx
```

## Google Drive

Drive フォルダ: https://drive.google.com/drive/folders/1jSFuaBXq3PC0426VPk8Y3DHSZrs70G1f

Cursor が予想・結果確認のたびに同じ4ファイルを更新します。Drive反映は md5/size 一致を確認してから報告します。

ChatGPT に渡す手順（原田さん）:

1. Google Drive から上記ファイルを開く（または PC に同期されたフォルダを開く）
2. ChatGPT のチャットに **ファイルを添付**する
3. 「今日の競馬と競艇の予想記入と集計を確認して」と指示する

## ChatGPT に伝えるとよい情報

- シート名は月別（例: `202609` = 2026年9月）。範囲は `202609`〜`202708`
- 1日5行（予想番号1〜5）
- 予想記入は A〜K 列、結果は L〜N 列
- 集計シートの B〜O 列は数式（触らない）

## 使わないファイル

- `競輪_個人_予想記入シート.xlsx`
- `競輪_個人_予想集計シート.xlsx`
- 提出用 `競輪予想/`

## Cursor 側の自動更新

原田さんが Cursor で次のように伝えると、上記 Excel に自動で書き込まれます。

- **予想**: 「今日の競馬と競艇を予想して」
- **結果**: 「昨日の結果を確認して」

原田さんが JSON を作ったり、コマンドを打つ必要はありません。
